# WireLint

Static Analysis for LabVIEW.

WireLint aims to provide an independent static-analysis tool for LabVIEW VIs, similar in purpose to NI's VI Analyzer. It is not affiliated with, endorsed by, or sponsored by National Instruments (NI). LabVIEW is a trademark of NI.
